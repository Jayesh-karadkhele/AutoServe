## Visual Design System Conformance

* **Color Palette**: Light ivory background (`#F8FAF9`), white elevated cards, soft cyan information badges, soft violet governance accents, charcoal typography (`#0F172A`).
* **Typography**: Inter / system sans-serif hierarchy, clear numerical readability, precise status pill badges.
* **Accessibility**: Screen reader skip links (`#main-content`), explicit ARIA attributes on modals and drawers, minimum 44px touch targets.
